# BMM Extras

Modded-material weapon support addon for [BROMAX's Many Melees](https://github.com/monroelogs984-maker/bmm).
Adds all 37 BMM weapon types in materials from Twilight Forest, The Undergarden, Better End,
Better Nether, Primal Magick, Wyrmroost, and Druidcraft Regrown.

Minecraft 1.21.1, NeoForge. Soft-depends on BMM. License: CC BY 4.0.
